MultiMesh for JAX: MPMD auto-sharding for JAX

MultiMesh for JAX: MPMD auto-sharding for JAX#

MultiMesh for JAX provides a framework for creating task contexts within jitted computations, allowing different subcomputations to be placed on different GPU submeshes. These task computations can be combined inside a global jit with data resharding across submeshes occurring automatically. MultiMesh therefore enable pipeline parallelism to be easily expressed. Standard Jax SPMD sharding idioms can be used within each task, enabling full N-dimension parallelism.

Familiar Transformation API

MultiMesh for JAX uses idiomatic JAX transforms to assign submesh contexts to functions or Flax modules

Plugin Installation

MultiMesh for JAX adds compiler and runtime functionality via the jax_plugins interface
